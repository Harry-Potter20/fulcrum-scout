# Fulcrum Scout

Live model-derived recruitment intelligence on the Fulcrum engine — a coherent **Discover → Understand → Recommend**
workflow (not a capability dump). Runs `fulcrum.scouting()` live: role-relative percentiles, over/under-performance,
player-print pizzas, a weighted-percentile Fit Finder, and cost-aware moneyball (market value from Sofascore).
Football + basketball, one engine. Data on Hugging Face datasets; refreshable.

**Deploy:** Streamlit Cloud → point at `app.py`. Set a `HF_TOKEN` secret if the datasets are private (they're public).
